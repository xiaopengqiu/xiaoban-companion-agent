# Supplementary license sources

The installed wheels/sdists for the following packages do not include a separate license file; the collector also reproduces their unchanged distribution metadata. Full upstream texts are preserved here:

- proxy_tools0.1.0: https://github.com/jtushman/proxy_tools/blob/master/LICENSE.txt (blob `078411c7399fbc0454f36cbe8c8cdbaaba7ebc95`). The package metadata labels it MIT, while the upstream LICENSE.txt says BSD; both are reproduced without resolving that discrepancy or granting new rights.
- standardwebhooks1.1.0: https://github.com/standard-webhooks/standard-webhooks/blob/main/libraries/python/LICENSE (blob `73732814a941cd54b621d6f789ecfaa87eab6267`). This is the Python library's MIT text, not the repository root's different license.
- svix1.99.1: https://github.com/svix/svix-webhooks/blob/v1.99.1/LICENSE.
- Microsoft WebView2 SDK1.0.3856.49: LICENSE.txt and NOTICE.txt copied verbatim from https://api.nuget.org/v3-flatcontainer/microsoft.web.webview2/1.0.3856.49/microsoft.web.webview2.1.0.3856.49.nupkg. The version matches the packaged Microsoft.Web.WebView2.Core.dll file/product version.

These files describe third-party components. They do not supply a license for the Xiaoban source repository.
