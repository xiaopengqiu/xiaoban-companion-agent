# 小伴 v0.5.0

新增可回复的 AI 主动关心和 Android 免费基础系统通知接入。本次同时提供 Windows EXE、便携 ZIP、Android 调试签名 APK 与 SHA256 校验文件；Android versionCode 为3，沿用上版调试签名，未提供 Android 应用内自动更新。

- Web、Windows 在线账户与 Android 新增关心消息。AI 使用用户明确授权的有效记忆、正在经历的事与近7日记录判断；无需联系、模型不可用或不满足权限/免打扰时不创建关心。
- 管理员可配置模型、分析频率、发信冷却、每天上限及极光基础推送参数；普通用户不能修改。当前 Sites 云端每小时运行一轮，分析间隔按60分钟整数倍设置；账号分批处理，时间可能延迟。
- 用户逐个账号开启授权，消息持久保存、共享已读状态并可接着回复。失败回复保留待回应，重试不会重复保存同一用户消息。
- Android 使用 JPush3.6.0/JPush6.3.0 的基础 REST API，捆绑国内五类厂商与FCM扩展。AppKey和公开SDK参数可由管理员配置；MasterSecret加密保存在服务端。华为/vivo/荣耀部分公开标识仍需随APK构建，界面会说明。
- 保留线上已有浏览器后台通知、流式聊天及 Windows 签名自动更新。

没有内置真实模型或推送密钥，不自动购买任何付费套餐。推送免费权益以极光/厂商账号实际状态为准，模型调用和服务器成本另计。普通用户仍需允许系统通知；厂商通道、包名和证书还需在平台正确开通。当前没有提供真机及第三方服务凭证，编译/签名/自动化测试不能当作真机锁屏、杀进程或穿戴同步已经验收。

配置步骤见 [Android免费通知指南](../android-native-care.md)。
