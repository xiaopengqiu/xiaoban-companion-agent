# 小伴 v0.4.1

Windows 便携版新增自动更新。启动后后台检查新版本，运行期间每六小时再检查；默认自动下载，下次启动安装，也可通过“窗口 → 检查更新 → 重启更新”立即升级。当前聊天不会被后台下载打断。

- 独立更新窗口显示版本、下载进度、说明和错误，支持关闭自动下载及手动检查。
- 更新清单使用固定公钥验证 Ed25519 签名，安装文件必须通过 SHA256、精确长度、平台和版本校验。
- 当前程序复制可信更新助手，正常退出后执行新版自检和替换；新版窗口与本机服务确认就绪后才认定成功。失败保留或恢复旧版，且不终止其他程序。
- 升级保留本机记录、设置及 WebView 登录资料；程序目录需要当前用户可写。
- 更新通过既有网站/R2 分发，不在客户端保存 GitHub 凭证。可执行文件的发布使用独立运维权限，应用管理员仍只拥有应用内授权范围。

**v0.3 及更早版本需要手动下载并改用本次 v0.4.1 一次，此后通过内置更新器升级。** 新安装可下载 `Xiaoban-Windows-portable.zip`，解压后双击 EXE。安装包仍为未做商业 Windows 代码签名的开发版。

源码验证：Python 211 项、Worker/D1/R2 50 项、Web Node 12 项通过。覆盖签名篡改、流式下载中断/超时、并发安装互斥、候选内置版本不符、已退出进程句柄仍被保留、启动失败、回滚、按钮异步状态与用户隔离。完整验收结果见下方验证记录。

Windows 构建与真实升级验收证据见 `desktop/VERIFICATION.md`；维护者后续发布流程见 `docs/desktop-updates.md`。

## Android 调试版附件

补充 `Xiaoban-Android-debug.apk`，编译版本0.4.1、versionCode2，支持 Android 10及以上。首次默认连接小伴云端，可使用同一云端账号。当前移动端提供登录/注册、行为手录、陪伴聊天、记忆、提醒收件箱与健康接入入口；真实手表、后台同步和系统推送仍待真机与凭证联调，Android 应用内自动更新尚未接入。

本次 APK 使用与旧调试包一致的签名，保留原包身份；未将它标作正式商店签名版。移动端生产源码与既有v0.4.1 tag一致，版本和云端地址通过显式 Flutter 构建参数设置。原有 Windows、源码包及校验附件保持不变，新增客户端专用 SHA256 校验清单。构建记录见主分支的 `mobile/VERIFICATION.md`。

后续客户端发布统一包含 Windows 和 Android 附件，操作流程见主分支 `docs/client-releases.md`。
